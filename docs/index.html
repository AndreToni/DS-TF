DS-TF Design Tokens

Documentação de referência dos tokens visuais do arquivo Figma DS-TF v1.1 (Light) — cor, tipografia, elevação e espaçamento, organizados no mesmo formato de referência usado pela documentação do Material Design.

Componentes com o selo Implementação — pacote ds-tf-ds já existem como React + Tailwind reais (Action Panel, Activity Feed, Alert, Avatar, Badge, Breadcrumbs, Button, Checkbox, Dialog, Divider, Navigation, Radio Button, Radio Card, Select, Slide-Over, Slider, Switch, Tabs, Text Area, Text Field, Toggle, Tooltip), prontos para npm install github:AndreToni/DS-TF. Algumas variantes específicas dentro de cada seção (ex. Multi Range do Slider, Select Dates/Multiple) ainda não foram portadas — cada seção indica isso onde aplicável.

Foundations

Cor

Os tokens de cor definem os papéis visuais usados em toda a interface — texto, superfícies, bordas, estados de feedback e destaque. Clique em um swatch para copiar o hex.

Foundations

Tipografia

Família tipográfica Inter. Escala completa de headlines, subheadlines, corpo de texto, caption, overline e botões.

Foundations

Elevação

Tokens de elevação combinam duas camadas de drop-shadow para criar profundidade progressiva, de xs a xl.

Foundations

Spacing

Escala de espaçamento em base 4px (1rem = 16px), usada em padding, margin, gap e demais propriedades de layout.

Navigation

Nav Item é a linha de navegação — ícone, label, badge de contagem (`countTone` escolhe a cor — `"error"` pra um contador urgente, por exemplo), tag "New", texto descritivo e chevron para expandir/colapsar (com filhos aninhados). Duas aparências para o estado selecionado: Default (fundo sutil) e Pill (fundo cheio). Nav Group agrupa itens sob um cabeçalho ("SECONDARY MENU"), e Nav Menu é o container da barra lateral — agora com `header`/`footer` livres (logo/switcher no topo, um botão fixado embaixo). Ver Side Nav pra uma barra lateral completa montada com esses três.

Implementação — pacote ds-tf-ds
import { NavMenu, NavGroup, NavItem } from "ds-tf-ds";

<NavMenu>
  <NavItem icon={<HomeIcon />} label="Dashboard" selected />
  <NavItem label="Notifications" count={4} />
  <NavGroup label="Secondary Menu">
    <NavItem label="Settings" />
  </NavGroup>
</NavMenu>

O atom "Group Headline" do print (com estados hover/selecionado, como um switcher de abas) não foi portado como componente clicável separado — `NavGroup` cobre apenas o cabeçalho estático de seção. Monte um switcher com `Tabs` se precisar dessa interação.

Tabs

Navegação entre visões relacionadas dentro de uma mesma página. Tab Item é o item isolado (linha simples, linha densa ou pílula), cada um com quatro conteúdos possíveis (simples, com badge, com ícone, com ícone e badge). Tab Nav agrupa vários itens em uma barra de navegação.

Implementação — pacote ds-tf-ds
import { Tabs, TabsList, TabsTrigger, TabsContent } from "ds-tf-ds";

<Tabs defaultValue="overview">
  <TabsList variant="line">
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="activity">Activity</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">...</TabsContent>
</Tabs>

Badge/ícone dentro do Tab Item são compostos livremente como `children` do `TabsTrigger`. Use `fullWidth` no `TabsList` para o modo "Full Width" e `density="dense"` para a variante compacta.
